## 5. 主题三态（Theme.kt ThemeMode）

- `system` / `light` / `dark`，持久化键 `ui_theme_mode`（与灯影同名）。
- `ThemeProvider` 用 `matchMedia('(prefers-color-scheme: dark)')` 跟随系统；手动选择后系统偏好不再覆盖。
- 切换即时生效：CSS 变量挂在 `document.documentElement`，同时同步 `<meta name="theme-color">`。
- 深色下 `textSecondary=#B6B6AD` 是灯影实测的 4.4:1 可读性修正值，勿改回浅色副文本。

## 7. 交互一致性（对齐 AGENTS.md §6）

- 二次确认：`ConfirmDialog`，危险操作用 `.btn-danger`（`--danger`），绝不用品牌色当警告色。
- 草稿保留：`DraftProvider`（`meow_ledger_drafts_v1`），切 Tab / 返回不丢表单。
- 空态出口：`EmptyState` 强制带「下一步」按钮。
- Tab 常驻：`Dock` 不随二级页消失；每个 Tab 独立页面栈，`switchTab` 不销毁其它栈。
- 二级页返回：`TopBar.onBack` → `nav.pop()`；栈空时 `pop` 幂等，不会退出应用。
- 深浅色：两套 glass/palette 全 token 化，调用点零改动（对齐 `CompositionLocalProvider` 注入口径）。
